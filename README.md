# FAQ Chatbot

React + Express project for Task 2.

Features:
- FAQ knowledge base
- Text preprocessing
- TF-IDF
- Cosine similarity
- Best matching answer
- Chat UI
- Express API

## Structure

faq-chatbot/

├── README.md
└── vite.config.js

## Run

npm install

Terminal 1:
npm run server

Terminal 2:
npm run dev
